# Impulso Marketing Studio — Next.js + Tailwind

Versión migrada de la landing a **Next.js App Router + TypeScript + Tailwind CSS v4**.

## Ejecutar localmente

```bash
npm install
npm run dev
```

Abrir `http://localhost:3000`.

## Estructura

- `app/page.tsx`: landing completa.
- `app/globals.css`: identidad visual, layout responsive y animaciones.
- `app/layout.tsx`: metadata y layout raíz.
- `public/assets/`: logo e imágenes del sitio.

El formulario es demostrativo: muestra una confirmación en el navegador. Para producción, conectarlo con una API, email, CRM o WhatsApp.
